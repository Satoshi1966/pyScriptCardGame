# PyScript 神経衰弱ゲーム（教材版）

HTML・CSS・Python（PyScript）で作った、ブラウザで遊べる神経衰弱ゲームです。HTML/CSSを学習済みの方が、Pythonのリスト・条件分岐・関数・イベント処理・DOM操作を学ぶためのサンプル教材です。

## 1. ゲームの内容

- 6種類の絵柄を2枚ずつ使った **12枚・6ペア** の神経衰弱です。
- カードを2枚選び、同じ絵柄なら表向きのまま残ります。
- 異なる絵柄なら約1秒後に裏向きへ戻ります。その間は別のカードを選べません。
- 2枚選ぶごとに「挑戦回数」が1増えます。
- 6ペアをすべて見つけるとクリアです。
- 「もう一度遊ぶ」でカードをシャッフルして最初から遊べます。
- 最少挑戦回数はブラウザの `localStorage` に保存されます（同じブラウザ・同じサイト内）。

## 2. ファイル構成

```text
pyscript_memory_game/
├── index.html   … 画面の構造、PyScriptの読み込み
├── style.css    … 配色・カード・画面レイアウト
├── main.py      … ゲームの処理（Python）

```

**ゲーム本体は3ファイル**です。画像やデータベースは使用しません。

## 3. 動作環境

- インターネット接続（PyScript 2024.7.1をCDNから読み込みます）
- JavaScriptが有効な比較的新しいWebブラウザ
- ローカルで起動するためのPython（`python -m http.server` を使用）

※ PythonはローカルHTTPサーバーを起動するために使います。ゲームのPythonコードはPyScriptを通じてブラウザ上で実行されます。

## 4. 起動方法

1. `index.html`、`style.css`、`main.py` を同じフォルダに置きます。
2. そのフォルダでターミナル（WindowsならPowerShellなど）を開きます。
3. 次のコマンドを実行します。

   ```bash
   python -m http.server 8000
   ```

   Windowsで `python` が使えない場合は `py -m http.server 8000` も試せます。
4. ブラウザで **http://localhost:8000/** を開きます。
5. 初回はPyScriptの読み込みに少し時間がかかる場合があります。
6. 終了するときはターミナルで **Ctrl + C** を押します。

> `index.html` をダブルクリックして `file://` で開く方法は推奨しません。外部の `main.py` がブラウザの制限で読み込めない場合があります。

## 5. 操作方法

1. 裏向きのカードをクリックします。
2. もう1枚クリックします。
3. 絵柄が一致すれば、その2枚は確定します。不一致なら約1秒後に戻ります。
4. 6ペアすべてをそろえるとクリアです。
5. もう一度遊ぶ場合は「🔄 もう一度遊ぶ」を押します。

## 6. コードの役割と重要ポイント

| ファイル・関数 | 役割 |
|---|---|
| `index.html` | ボタンや成績表示欄を用意し、`main.py` を読み込む |
| `style.css` | カードの色、4列の並び、スマートフォン向け表示を設定 |
| `SYMBOLS` | カードに使う6種類の絵柄を指定 |
| `random.shuffle(cards)` | カードの順番をランダムにする |
| `new_game()` | カードとスコアを初期化し、クリックイベントを登録 |
| `select_card(index)` | カードをめくり、2枚そろったら一致判定 |
| `close_unmatched()` | 不一致の2枚を一定時間後に裏返す |
| `draw_card()` / `draw_all()` | Pythonの状態をHTML画面へ反映 |
| `update_score()` | 挑戦回数、ペア数、ベスト記録を表示 |

**処理の流れ：** ゲーム開始 → シャッフル → 1枚目選択 → 2枚目選択 → 一致判定 → 画面更新 → 全ペア一致でクリア。

## 7. カスタマイズ課題

### 基本課題

1. `main.py` の `SYMBOLS` を変更し、果物以外の絵文字にする。
2. `WAIT_SECONDS = 1.0` を `1.5` に変更し、裏返るまでの時間を変える。
3. `style.css` の `.card` の背景色を変更する。
4. `index.html` のタイトルや説明文をオリジナルに変更する。

### 応用課題

1. 8ペア・16枚のゲームにする（`SYMBOLS` に8種類を指定し、成績表示の初期値も調整する）。
2. クリア時に挑戦回数に応じた評価メッセージを表示する。
3. カードの列数や大きさを変更し、スマートフォンでも見やすくする。
4. ベスト記録をリセットするボタンを追加する。

### 自由制作

動物・乗り物・食べ物などのテーマを決め、配色、タイトル、カード、追加機能を統一して、自分の作品に仕上げましょう。

## 8. よくあるトラブル

| 症状 | 確認すること |
|---|---|
| 画面は表示されるがカードが出ない | インターネット接続、ブラウザの開発者ツールのConsole、`main.py` の読み込みを確認 |
| `localhost:8000` が開かない | HTTPサーバーを起動したターミナルが動作中か確認 |
| `python` が見つからない | PythonのインストールやPATHを確認。Windowsでは `py` も試す |
| 修正しても表示が変わらない | 保存済みか確認し、ブラウザを再読み込みする |
| ベスト記録が残らない | ブラウザのプライベートモードやサイトデータの削除設定を確認 |
